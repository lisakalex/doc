Alphabet Soup

Every abbreviation this course has used or will use, expanded — with the one thing about each that actually matters. Green marks the ones already taught; the rest are ahead of you.

grouped by domain type to filter updated 2026-09-13

Identity & access

Who you are, what you may do

IAM taughtIdentity and Access Management — global service; the ARN's region field is empty. Controls every request in the account.
STS taughtSecurity Token Service — mints temporary credentials. The doorman that checks a role's trust policy.
ARN taughtAmazon Resource Name — arn:partition:service:region:account:resource. An empty region means a global service.
MFA taughtMulti-Factor Authentication — protects sign-in and any API call whose policy demands aws:MultiFactorAuthPresent. Not the credential itself.
TOTP taughtTime-based One-Time Password — the 6-digit authenticator-app kind. Your al-iphone and root-phone-totp devices.
FIDO2 / WebAuthn taughtthe passkey standard — asymmetric, phishing-resistant. Root's other MFA device, held in Google Password Manager.
SigV4 taughtSignature Version 4 — AWS request signing. Symmetric: AWS holds a copy of your secret, unlike SSH.
HMAC taughtHash-based Message Authentication Code — the secret is the key you hash with, not the thing hashed.
OIDC taughtOpenID Connect — identity layer over OAuth 2.0. How GitHub Actions and EKS pods get AWS credentials with no stored secret.
JWT taughtJSON Web Token — signed claims. The ones that matter: iss, sub, aud, exp.
IRSA taughtIAM Roles for Service Accounts — EKS pods assume roles via OIDC. Your app_role is scoped this way, minus the aud condition.
SAMLSecurity Assertion Markup Language — the older XML federation standard. Corporate SSO into AWS still often uses it.
SCPService Control Policy — Organizations-only. Sets a permission ceiling for whole accounts; never grants anything.
RBAC / ABACRole- / Attribute-Based Access Control — permissions by role, or by tag-matching conditions. ABAC scales better in large orgs.
IdC / SSOIAM Identity Center (formerly AWS SSO) — the role-assumption pattern from Lesson 2.5, with a login page in front.
AKIA / ASIA taughtaccess key prefixes — AKIA = permanent IAM user key. ASIA = temporary STS credentials, needs a session token too.
IMDSInstance Metadata Service — 169.254.169.254. IMDSv1's lack of session tokens caused the 2019 Capital One breach; always require v2.

Encryption & secrets

Keys, and who holds them

KMS taughtKey Management Service — regional. Holds keys that never leave it; you send it small things, never your data.
CMK taughtCustomer Master Key — legacy term. AWS now says "KMS key" or "customer managed key". Your Terraform comments still say CMK, as does most of the internet.
DEK taughtData Encryption Key — the 256-bit key that actually encrypts your object. Returned by GenerateDataKey twice: plaintext and wrapped.
SSE taughtServer-Side Encryption — SSE-S3 (AWS's key), SSE-KMS (a KMS key), SSE-C (you supply the key per request).
DSSE-KMSDual-layer SSE — two independent encryption layers for regulated workloads. Roughly double the KMS cost.
CSEClient-Side Encryption — you encrypt before upload. AWS never sees plaintext — and never helps you recover it.
HSMHardware Security Module — tamper-resistant key hardware. CloudHSM is the single-tenant option when KMS's shared model won't pass audit.
AES-256 taughtAdvanced Encryption Standard — the symmetric cipher behind SSE. "AES256" in an S3 response means SSE-S3.
TLS taughtTransport Layer Security — encryption in transit. Independent of encryption at rest; enforce with aws:SecureTransport.
ACMAWS Certificate Manager — free public TLS certs that auto-renew, usable only by AWS services (ALB, CloudFront, API Gateway).
SSMSystems Manager — Parameter Store lives here: cheap config and secrets. Secrets Manager is the pricier one with rotation built in.
WORM taughtWrite Once Read Many — S3 Object Lock. Blocks deletion even by root for a retention period. The real ransomware control.

Storage

Where bytes live

S3 taughtSimple Storage Service — object store. Global namespace, regional data, flat keys.
EBSElastic Block Store — a virtual disk for one EC2 instance. AZ-bound; a snapshot is how it crosses.
EFS taughtElastic File System — NFS with real directories and instant rename — at roughly 13× S3's price per GB.
IAInfrequent Access — S3 Standard-IA, One Zone-IA. Cheaper storage, charged per retrieval, 30-day minimum.
CRR / SRRCross- / Same-Region Replication — the only thing that survives losing a region or an account. Requires versioning.
ETag taughtEntity Tag — an object's version fingerprint. The MD5 for simple uploads — but not for multipart or SSE-KMS objects.
MPU taughtMultipart Upload — large objects in parts. Unfinished ones bill forever and are invisible in listings; abort them with a lifecycle rule.

Compute & containers

Where code runs

EC2Elastic Compute Cloud — virtual machines. The oldest and most configurable option, and the one you manage most.
ECSElastic Container Service — AWS's own container orchestrator. Simpler than Kubernetes, AWS-only.
EKS taughtElastic Kubernetes Service — managed Kubernetes. Control plane bills $0.10/hr whether or not anything runs — your August credit burn.
ECR taughtElastic Container Registry — private Docker registry. In your Terraform, deliberately unsuffixed so all workspaces share one.
AMIAmazon Machine Image — the boot image for an EC2 instance. Region-scoped; must be copied to travel.
ASGAuto Scaling Group — keeps N instances alive across AZs and replaces unhealthy ones.
OCIOpen Container Initiative — the image and runtime spec. "OCI image" means the standard Docker made and then standardised.

Networking

Module 6, and most surprise bills

VPCVirtual Private Cloud — your private network inside a region. Everything with an IP lives in one.
AZ taughtAvailability Zone — an independent failure domain. Names like us-east-1a are shuffled per account; AZ IDs are the stable ones.
CIDRClassless Inter-Domain Routing — the 10.0.0.0/16 notation. The /n counts fixed bits; smaller n = bigger network.
SGSecurity Group — stateful instance firewall. Allow-only. Return traffic is automatic.
NACLNetwork Access Control List — stateless subnet firewall. Allow and deny, and you must write both directions.
IGW / NATInternet Gateway / Network Address Translation — IGW is free; NAT Gateway costs ~$0.045/hr plus ~$0.045/GB processed.
VPCeVPC Endpoint — reach AWS services without the internet. The S3 Gateway endpoint is free — use it instead of routing S3 traffic through NAT.
ENIElastic Network Interface — a virtual NIC. Pods on EKS get real VPC IPs through these, which is why IP exhaustion is an EKS concern.
ALB / NLBApplication / Network Load Balancer — ALB understands HTTP and routes on paths and headers; NLB is layer 4, faster, and preserves source IP.
CDNContent Delivery Network — CloudFront. Also the cheap path for egress: origin→CloudFront transfer is free.
WAF taughtWeb Application Firewall — layer-7 filtering. Global when attached to CloudFront, regional on an ALB.
TGW / DXTransit Gateway / Direct Connect — hub for many VPCs; dedicated private line from your own datacentre.

Data stores

Tables, and what they charge for

DDB taughtDynamoDB — managed NoSQL. Single-digit-millisecond reads if your access pattern matches the key design; painful if it doesn't.
PK / SKPartition Key / Sort Key — together the primary key. The partition key decides which physical partition holds the item — choose it badly and you get a hot partition.
GSI / LSIGlobal / Local Secondary Index — query by something other than the primary key. A GSI is a separate replica with its own capacity and cost.
RCU / WCURead / Write Capacity Unit — provisioned mode. 1 WCU = one 1 KB write per second; 1 RCU = one 4 KB strongly-consistent read.
RRU / WRURead / Write Request Unit — on-demand mode: same units, billed per request instead of reserved. ~$1.25 per million writes.
TTLTime To Live — DynamoDB deletes expired items for free, eventually — up to 48 hours late. Not a scheduler.
RDSRelational Database Service — managed Postgres/MySQL/etc. Aurora is AWS's own engine with storage split from compute.

Reliability & observability

Modules 12 and 13

SLI / SLO / SLAIndicator / Objective / Agreement — what you measure, the target you set, the contract with money attached. Your SLO should be stricter than your SLA.
RTO / RPORecovery Time / Point Objective — how long until you're back, versus how much data you can afford to lose. Different questions; people conflate them.
MTTR / MTBFMean Time To Recovery / Between Failures — modern SRE optimises the first; you cannot make failures stop.
p50 / p99percentile latency — p99 = the slowest 1%. Averages hide exactly the requests your users complain about.
CW taughtCloudWatch — metrics, logs, alarms. Custom metrics and log ingestion are where the bill comes from, not the dashboards.
OTelOpenTelemetry — vendor-neutral tracing and metrics. The reason you don't have to rewrite instrumentation when you change backend.
CloudTrail taughtthe audit log of API calls — who called what, when, from where. Where a Decrypt or AssumeRole shows up with its caller identity.

Delivery & supply chain

Modules 8, 9 and 11

IaC taughtInfrastructure as Code — the infrastructure is a reviewable artefact, not a memory of what someone clicked.
HCL taughtHashiCorp Configuration Language — what your .tf files are written in.
CFN / CDKCloudFormation / Cloud Development Kit — AWS's own IaC, and a way to generate it from TypeScript or Python.
CI / CDContinuous Integration / Delivery — CI proves the change is sound; CD gets it to production.
SBOMSoftware Bill of Materials — the manifest of everything inside your image. Answers "are we affected?" in minutes rather than days.
CVECommon Vulnerabilities and Exposures — the public ID for a known flaw, e.g. CVE-2021-44228 (Log4Shell).
SAST / DASTStatic / Dynamic Application Security Testing — reading the code versus attacking the running thing.
GitOpsgit as the source of truth for deploys — a controller reconciles the cluster toward the repo, so drift is visible as a diff.

Kubernetes

Module 10, from zero

K8sKubernetes — "K" + 8 letters + "s". Not a word anyone says out loud except as "kates".
SA taughtServiceAccount — a pod's identity inside the cluster. The sub claim in an IRSA token names one.
HPA / VPAHorizontal / Vertical Pod Autoscaler — more pods, or bigger pods. Horizontal is almost always the right instinct.
PDBPod Disruption Budget — the minimum that must stay up during voluntary disruption — node drains, upgrades. Not crashes.
CRDCustom Resource Definition — teaches the API new object types. How operators extend Kubernetes.
CNIContainer Network Interface — the pod networking plugin. On EKS it gives pods real VPC IPs, which is why subnet sizing matters.

Cost & compliance

Module 14, and the words lawyers use

FinOpscloud financial operations — treating spend as an engineering metric with an owner, not a monthly surprise.
RI / SPReserved Instance / Savings Plan — commit to spend for 1–3 years for up to ~70% off. Savings Plans are the flexible successor.
TCOTotal Cost of Ownership — including the engineer-days. The $10 S3 rename that costs three deploys is the example.
GDPR taughtGeneral Data Protection Regulation — data protection, not "digital rights". Does not require EU data to stay in the EU.
SCC / DPF taughtStandard Contractual Clauses / EU-US Data Privacy Framework — the two lawful routes for transferring EU personal data to the US.
DORA taughtDigital Operational Resilience Act — EU financial-sector rules on ICT risk and third-party concentration. Bites harder than GDPR on cloud choice.
EIOPA / IVASS taughtEU insurance regulator / its Italian national counterpart — where cloud-outsourcing guidance for insurers actually comes from.
