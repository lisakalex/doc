Keys, Not Paths

keyThe whole string identifying an object. The slash is just a character.

Recommendation: keep 01. Not because it is the most striking — 03 and 04 are — but because six lessons already use it and a course that changes clothes every module reads as six unrelated documents. Switching is only worth it if all seven change together.

If you do want a second look in play, the honest pairing is 01 for lessons, 05 for architecture pages: different job, visibly different artefact, no confusion about which is which. And 06 for the cost and audit pages, which are scanned rather than read.

Specimen source lives with the course in lessons/; the head block of any existing lesson is the system in 01, ready to copy.
