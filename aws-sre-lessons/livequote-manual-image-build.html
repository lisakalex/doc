LiveQuote: Build and Push Images by Hand

How to rebuild the LiveQuote cmaweb (nginx) and php-fpm images from a CodeCommit branch on the Jenkins host and push them to Amazon ECR. The example uses branch ITST0113 and build 166. Change both to match your release.

host <jenkins-host> user jenkins source eu-west-2 registry eu-central-1 2 images

Steps 1–3

Get a clean checkout

1. Switch to the jenkins user and set the variables. The sudo -su jenkins command asks for your own password. Variables you set before switching users don't carry over, so set them after.

sudo -su jenkins cd ~/liveqoute/checkmarx2.0 BRANCH=ITST0113 BUILD=166 REGISTRY=<account-id>.dkr.ecr.eu-central-1.amazonaws.com REPO=livequote-repo

2. Remove the old checkout.

ls -l rm -rf "$BRANCH"/

Git pack files are read-only, so a plain rm -r stops to ask about each one. Add -f to skip the prompts. You don't need sudo because jenkins owns the directory. Only use sudo rm -rf if a previous run left files owned by root.

3. Clone the branch from CodeCommit.

git clone --branch "$BRANCH" \ https://git-codecommit.eu-west-2.amazonaws.com/v1/repos/<codecommit-repo> \ "$BRANCH" ls "$BRANCH"/ # expected: cma CMALoader containers containers.json environments.json # lambda-layers.json README.md S3

If the clone returns 403

A 403 error means CodeCommit rejected the credentials. Your SSO or email password won't work here. Use one of these options:

A. HTTPS Git credentials. In the IAM console, open Users → your user → Security credentials → HTTPS Git credentials for AWS CodeCommit → Generate. When git prompts you, enter the generated username (in the form name-at-<account-id>) and the generated password.

B. AWS CLI credential helper. This uses the AWS credentials in your shell, which must have CodeCommit access in eu-west-2.

# option B git config --global credential.helper '!aws codecommit credential-helper $@' git config --global credential.UseHttpPath true # if git cached a bad username or password, clear it before you try again git credential reject <<< $'protocol=https\nhost=git-codecommit.eu-west-2.amazonaws.com'

Steps 4–5

Build both images

4. Copy the application code into both build contexts. Both Dockerfiles run COPY ./cma/ ..., so each build context needs its own copy of cma/.

cd "$BRANCH" cp -R cma/ ./containers/php-fpm/ cp -R cma/ ./containers/cmaweb/ ls -l containers

5. Build the images.

cd containers/cmaweb docker build -t "$REPO:cmaweb_$BUILD" . cd ../php-fpm docker build -t "$REPO:php-fpm_$BUILD" .

Check the build output

cmaweb: all 12 steps finish, including copying cert/nginx-lq.crt, cert/nginx-lq.key, nginx.conf and mime.types.

php-fpm: step 6 prints PDO MySQL OK, SSL_CA constant = ....

Steps 6–8

Log in and push

6. Get AWS credentials for the target account. Export temporary credentials for account <account-id>. You can copy them from the AWS access portal under Command line or programmatic access.

export AWS_ACCESS_KEY_ID="<from portal>" export AWS_SECRET_ACCESS_KEY="<from portal>" export AWS_SESSION_TOKEN="<from portal>" aws sts get-caller-identity # confirm the Account is <account-id>

Never paste real keys

Don't paste real keys into tickets, chat or docs. These credentials expire, but anyone who has them can use them until they do.

7. Log in to ECR.

aws ecr get-login-password --region eu-central-1 \ | docker login --username AWS --password-stdin "$REGISTRY"

The response should be Login Succeeded. You'll also see a warning that the credentials are stored unencrypted in /var/lib/jenkins/.docker/config.json. The warning is expected. The ECR token expires after 12 hours. To remove it sooner, log out when you finish (step 10).

8. Tag and push.

docker tag "$REPO:cmaweb_$BUILD" "$REGISTRY/$REPO:cmaweb_$BUILD" docker push "$REGISTRY/$REPO:cmaweb_$BUILD" docker tag "$REPO:php-fpm_$BUILD" "$REGISTRY/$REPO:php-fpm_$BUILD" docker push "$REGISTRY/$REPO:php-fpm_$BUILD"

Each push ends with a line like cmaweb_166: digest: sha256:... size: .... Record both digests in the change ticket.

Steps 9–10

Verify and clean up

9. Verify the images in ECR.

aws ecr describe-images --region eu-central-1 --repository-name "$REPO" \ --image-ids imageTag="cmaweb_$BUILD" imageTag="php-fpm_$BUILD" \ --query 'imageDetails[].[imageTags[0],imageDigest,imagePushedAt]' --output table

10. Clean up.

docker logout "$REGISTRY" unset AWS_ACCESS_KEY_ID AWS_SECRET_ACCESS_KEY AWS_SESSION_TOKEN exit # leave the jenkins shell

To deploy the new images, update the image tags in containers/taskdef-livequote-{dev,preprod,prod}.json.
