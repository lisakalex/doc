An index of the 332 books in ~/Documents/books, so a reading pointer in these notes names a real heading on a real page instead of being guessed from a filename.
toc.tsv.gz 68,502 section headings pulled from each book's own table of contents: path, depth, page, title
books.tsv one row per book: path, pages, outline entries
find-reading.sh look a topic up 
./find-reading.sh -s 'workspace'       # the devops/read shelf only
./find-reading.sh -i 'secret'          # infra books, skipping java/python/...
./find-reading.sh -b Brikman 'state'   # one book

Built with mutool show <file> outline for PDFs. EPUBs defeat mutool — it reads them as corrupt PDFs and returns nothing — so those are parsed from their toc.ncx instead; without that, Kubernetes in Action 2e would be absent from the index entirely while appearing to be covered.

51 of the 332 books still have no table of contents at all and contribute nothing, including the 1,244-page AWS DevOps Engineer Professional Certification Guide, which has to be searched by hand.

Pages in this index are PDF pages, which is what a viewer jumps to. Several of these are reflowed ebooks with no printed folios at all, so there is no printed page number to convert to.

Manning titles (Terraform in Action, Kubernetes in Action) use named destinations rather than page numbers, so they index with a - page and get cited by section number, which is more durable anyway.

That last block is not incidental. IRSA, the PDB/drain interaction and Alertmanager routing are three of the mechanisms this repo leans on hardest, and they are the three the library is quietest about — which is roughly the state of the published material generally. For those, the primary sources are the AWS and Kubernetes docs and the upstream chart values, and the entries in questions/ are the substitute.

Rebuilding

The index is derived from a library that is not in this repo, so it is committed rather than generated on clone.

find ~/Documents/books -type f \( -iname '*.pdf' -o -iname '*.epub' \) -print0 |
while IFS= read -r -d '' f; do
  mutool show "$f" outline 2>/dev/null   # -> path, depth, page, title
done
