The record

Questions

One entry per question, each ending in what I thought the answer was before checking. That last part is the reason these exist.

001 Does removing a git remote guarantee a push can't reach GitHub?

No. git remote remove origin deletes three lines from .git/config and stops exactly one thing — a bare git push with no arguments, because the branch's upstream tracking goes with it.

safety answered
002 Brikman says workspaces are the wrong way to separate environments. aws-sre uses workspaces to separate environments. Who is right?

Brikman is right, and env.tf already says so in a comment — but the repo is weaker than that comment implies. The three env/backend-*.hcl files are byte-identical apart from a comment, so the per-environment backend config is decoration: -backend-config=env/backend-prod.hcl selects nothing.
